IT Solutions Tools & Technologies

These six tools support common IT workflows, including network analysis, infrastructure management, monitoring, security assessment and system administration.

1. Zabbix

An open-source monitoring platform used to monitor servers, network devices, applications and infrastructure performance.

2. Wireshark

A network protocol analyzer used to inspect network traffic and help diagnose connectivity and communication problems.

3. GLPI

An IT service management and asset-management platform used to organize support requests, inventory and IT service records.

4. Ansible

An automation tool used to configure systems, manage infrastructure and repeat common administration tasks.

5. Proxmox VE

A virtualization platform used to manage virtual machines and containers for supported infrastructure environments.

6. Greenbone Community Edition

A vulnerability assessment solution used to identify potential security weaknesses in authorized systems.
