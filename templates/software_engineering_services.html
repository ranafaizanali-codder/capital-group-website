Software Engineering Tools & Technologies

These six tools support common software engineering workflows, including development, source control, testing, containerization and continuous integration.

1. Visual Studio Code

A source-code editor used for writing, navigating, debugging and maintaining software projects through extensions and development tools.

2. Git

A distributed version-control system used to track code changes, manage branches and support collaborative software development.

3. GitHub

A code-hosting and collaboration platform for repositories, code reviews, issue tracking and team development workflows.

4. pytest

A Python testing framework used to write and run automated tests, helping verify application behaviour and identify regressions.

5. Docker

A containerization platform used to package applications with their dependencies for more consistent development and deployment environments.

6. Jenkins

An automation server used to build, test and support continuous-integration and continuous-delivery workflows.
